This project embeds the [Dancing Script](https://fonts.google.com/specimen/Dancing+Script) typeface, used under the [SIL Open Font License 1.1](https://openfontlicense.org/), to render a typed signature on the filing package. The font file ships as `public/fonts/signature-script.woff` and its licence travels beside it as `public/fonts/signature-script-LICENSE.txt`; the OFL requires the licence to accompany the font, so the two files must stay together.
